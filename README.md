# Student Management System - Django CRUD

A simple **Django Student Management System** that performs complete CRUD operations using Django ModelForms. The project also includes custom form validation to ensure that only valid student data is stored in the database.

## Features

- Add new students
- View student records
- Update student information
- Delete student records
- Django ModelForm implementation
- Custom form validation
- Name validation
- Age validation
- Email validation
- Database integration
- User-friendly interface

## Tech Stack

- Python
- Django
- SQLite / MySQL
- HTML
- CSS
- Django ModelForms
